# 島の開拓者たち — オンライン対戦

Discordで通話しながら遊ぶことを前提にした、ブラウザ版の開拓ボードゲームです。
一人が部屋を立てると **4文字の合言葉** が発行され、それを共有すれば全員が同じ盤面に入れます。

チャット機能はあえて入れていません（通話で話す前提のため）。代わりに、自分の番が来ると
通知音が鳴り、ブラウザのタブに「● あなたの番」と表示されます。

---

## 起動する

```bash
npm install
npm start
```

`http://localhost:3000` が開きます。Node.js 18 以上が必要です。

## みんなで遊べるようにする

自分のPCで動かしたサーバーに、外から入ってもらう必要があります。手軽な順に3つ。

**1. 同じ家・同じLANにいる場合**
自分のローカルIP（`192.168.x.x` など）を調べて `http://192.168.1.20:3000` を共有するだけです。

**2. ネット越しに遊ぶ（いちばん手軽）**
Cloudflare Tunnel を使うと、公開URLが一時的に発行されます。

```bash
npm start                                  # 別のターミナルで起動しておく
cloudflared tunnel --url http://localhost:3000
```

表示された `https://xxxx.trycloudflare.com` をDiscordに貼ってください。
ngrok を使う場合は `ngrok http 3000` でも同じことができます。

**3. 常時ホスティングする**
Render / Railway / Fly.io などにそのままデプロイできます。ビルド手順は不要で、
起動コマンドは `node server.js`、ポートは環境変数 `PORT` を見ています。
無料プランはアイドル時にスリープすることがあるので、その場合は最初のアクセスに
数十秒かかります。

## 部屋ごとに変えられる設定

部屋主だけがロビーで変更できます。ゲーム開始後は固定されます。

| 設定 | 内容 |
| --- | --- |
| 最大人数 | 3〜6人。5人以上を選ぶと拡張ボードが自動でオンになります |
| 勝利点 | 8 / 10 / 12 / 14点先取 |
| 拡張ボード | 19マス（標準）↔ 30マス（5〜6人拡張）。港も9→11に増えます |
| 特別建設フェイズ | 5〜6人戦のルール。他人の手番が終わるたびに建設だけ行えます |
| 6と8を隣接させない | 数字チップを配り直して赤数字が隣り合わないようにします |
| 弱者を守る盗賊 | 2点以下のプレイヤーからは資源を奪えません |
| 最初の1周は7を振り直す | 序盤の事故を防ぐハウスルール |
| 7で捨て始める手札 | 7 / 9 / 11枚。多くすると手札を抱えやすくなります |

## 実装されているルール

- 初期配置（順番→逆順のスネークドラフト、2周目は隣接地形から資源を獲得）
- 産出、距離ルール、街道の接続判定（他人の建物で分断される点も含む）
- 盗賊：7で手札を半分捨てる → 移動 → 隣接プレイヤーから1枚奪う
- 港（3:1／資源別2:1）と銀行交易、プレイヤー間の交易提案・承諾・成立
- 発展カード5種（騎士・街道建設・発見・独占・勝利点）。購入した手番には使えません
- 最長交易路（5本以上）と最大騎士力（3枚以上）、勝利点の自動計算
- 銀行の資源切れルール（複数人が要求して足りない場合は誰も受け取らない）
- 5〜6人拡張の盤面・特別建設フェイズ

**未実装：** 「航海者」「都市と騎士」などの大型拡張。盤面生成とオプションの仕組みは
分離してあるので、`game.js` の `buildBoard()` と `applyAction()` に追加する形で
拡張できます。

## 途中で回線が切れたら

ブラウザを閉じたり再読み込みしても、同じ端末なら自動で同じ席に戻ります
（`localStorage` にIDを保存しています）。他のプレイヤーには「切断中」と表示され、
ゲームはその人の番で待機します。部屋は全員が切断してから3時間で破棄されます。

## 動作確認

```bash
npm test
```

盤面の位相（オイラーの多面体定理・頂点の次数）を検証したうえで、
3〜6人のランダム自動対戦を30局まわし、資源の総数保存・距離ルール・
コマ数の整合性が崩れないことを確認します。

## ファイル構成

```
server.js        ルーム管理と通信（Socket.IO）
game.js          ルールエンジン。盤面生成から勝敗判定まで
public/index.html  画面の骨組み
public/client.js   盤面描画と操作
public/style.css   見た目
test.js          自動対戦テスト
```

サーバーが唯一の審判です。手札の中身や発展カードは本人にしか送られないため、
クライアントを改造しても他人の手札は見えません。
